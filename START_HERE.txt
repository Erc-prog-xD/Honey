🔄 COMO FUNCIONA A CONEXÃO
────────────────────────────────────────────────────────────────────────────

1. React Component
   └─→ chama buscarApiarios()

2. apiarioService.js
   └─→ chama apiFetch('/api/Apiario/BuscarApiariosUserLogado')

3. api.js (apiFetch)
   ├─ Detecta URL: http://localhost:8080
   ├─ Adiciona headers (Content-Type, Authorization)
   ├─ Log: [API Request] POST http://localhost:8080/api/...
   ├─ Faz fetch
   └─ Log: [API Response] 200 OK

4. Backend (.NET) recebe
   ├─ Valida token JWT
   ├─ Processa requisição
   └─ Retorna JSON com dados

5. api.js processa resposta
   ├─ Parse JSON
   ├─ Log: [API Data] {...}
   ├─ Retorna dados ou lança erro
   └─ Se 401, limpa localStorage

6. Serviço retorna dados
   └─→ Componente usa os dados

⚠️ ERROS COMUNS E SOLUÇÕES
────────────────────────────────────────────────────────────────────────────

❌ "Access to fetch at ... blocked by CORS policy"
   → Backend não está aceitando requisições
   → Solução: Reiniciar Backend com `dotnet run`

❌ "TypeError: Failed to fetch"
   → Backend não está rodando
   → Solução: Iniciar Backend em novo terminal

❌ "HTTP 401 Unauthorized"
   → Token expirado
   → Solução: Fazer logout e login novamente

❌ "HTTP 404 Not Found"
   → Endpoint não existe ou está errado
   → Solução: Verificar no Swagger (localhost:8080/swagger)

❌ "SyntaxError: Unexpected token < in JSON at position 0"
   → Resposta é HTML em vez de JSON
   → Solução: Verificar if endpoint está correto

Para mais soluções: Consulte CONEXAO_FRONTEND_API.md
